CAR RENTAL SYSTEM - RELEASE PACKAGE
=====================================

STARTING THE PROGRAM

WINDOWS
--------
Double-click:
    Windows - Start Car Rental System.bat

If Python 3 is not installed, the launcher will tell you what to install.

macOS
-----
Double-click:
    macOS - Start Car Rental System.command

If macOS blocks the file, right-click it and choose Open.
Python 3 is required.


IMPORTANT
---------
This release includes the complete source code and all application folders.
The application uses Python Tkinter and SQLite, which are required by the
program. No third-party Python packages are required according to the
project README.

ABOUT THIS PACKAGE
------------------
This package is designed for easy distribution. The Windows and macOS
launchers are included so users can start the program by clicking one file.

A native Windows .exe and native macOS .app are platform-specific builds.
They cannot be reliably produced for both operating systems from this
Linux build environment without the respective platform build toolchains.
